# 故障排查

| 现象 | 下一步 |
| --- | --- |
| No reachable local proxy found | 开启代理客户端，查看真实 HTTP/混合端口，再指定 `-ProxyUrl` 安装。 |
| 有监听但没有改善 | 指定真实 HTTP/混合端口，避免 SOCKS-only 或其他服务；用 `Diagnose.ps1 -Network` 检查匿名请求。 |
| 提示先退出 ChatGPT | 等当前任务结束，从菜单完全退出；只关窗口可能仍在后台。工具不强行结束它。 |
| 找不到应用 | 确认已安装桌面版；其他安装布局可用 `-AppPath` 指定应用可执行文件。 |
| 应用更新后图标丢失或打不开 | 自动发现的商店应用每次重新定位；重装 Bridge 可刷新图标。手动应用路径变化后需重新指定。 |
| 端口改变 | 重新运行 `Install.ps1 -ProxyUrl http://127.0.0.1:新端口`。 |
| 公司策略不允许运行脚本 | 联系管理员采用符合组织策略的部署方式；不要禁用组织安全策略。 |
| 只有 Work 重连 | 分别验证普通聊天和 Work；匿名 HTTP 成功不能替代 Work 验证，可能仍需应用更新或进一步排查。 |
| 原图标正常、新图标异常 | 完全退出后分别测试；确认本地代理链路，必要时恢复原图标使用。 |

`ExecutionPolicy Bypass` 只通过命令行用于当前脚本宿主；安装器不永久修改执行策略。这也不会覆盖组织强制策略。

不要先清缓存、退出账号、删数据、重装应用或重置整个网络。这里的工具不需要这些操作。提交 issue 时提供 Windows / PowerShell / 应用版本、代理客户端名称、检查结果和普通聊天/Work 的区别即可；分享输出前检查是否包含本地路径，勿附订阅、密码、令牌或完整私人日志。

不提供代理服务、节点可用性保证、账号地区判断或网络环境支持保证。
